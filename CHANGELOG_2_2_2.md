# week. 2.2.2: перенос личного расписания в класс

Во вкладке «Группы» только для администратора появится кнопка **«Перенести моё расписание»**. Сначала выбери класс, затем нажми кнопку. week. загрузит актуальные школьные уроки именно твоего аккаунта из Supabase и предложит заменить расписание выбранного класса. После подтверждения эти уроки станут общими для учеников класса.

**Что важно:**

- Копируются только уроки с `kind = school`, а не дополнительные занятия (`extra`) и не личные задачи.
- Личные уроки остаются у тебя в базе. Если ты участник класса, календарь, как и раньше, показывает общие уроки вместо личных.
- При импорте общее расписание выбранного класса **полностью заменяется**. Перед действием показаны название класса, число уроков и предупреждение.
- При пустом или некорректном исходном расписании замена не происходит.
- Запись выполняет существующая серверная функция `week_replace_class_schedule`, которая проверяет роль `week_admins` и делает замену в транзакции. Другие участники класса не могут выполнить перенос.
- SQL-миграция не требуется, если уже установлена `MIGRATION_2_2_CLASSES.sql` и выданы права администратора. Ошибка `public.public_profiles` исправляется отдельно установкой `MIGRATION_2_1.sql`.
