# week.

Небольшой планировщик для себя и друзей. Здесь можно собрать дела на день, записать постоянные занятия и договориться о совместных планах. Текущая версия оптимизирована для небольшой группы, ориентировочно до 50 активных пользователей. Это не встроенное ограничение регистрации и не гарантированная цифра без проверки нагрузки.

week. работает в браузере и на телефоне. Его можно добавить на главный экран как приложение.

## Как начать

Открой сайт, зарегистрируйся по email и паролю или войди в свой аккаунт. При первом входе week. предложит указать школьное расписание и дополнительные занятия. Если ты вступил в класс, школьное расписание уже будет общим, а в личной настройке останутся дополнительные занятия. Если они тебе не нужны, этот шаг можно пропустить.

После входа откроется раздел «Сегодня». Нажми «+ Добавить задачу», чтобы записать первое дело.

При запуске на несколько секунд появляется заставка с советом на день. Логотип подстраивается под светлую или тёмную тему.

## Группы и классы

Во вкладке «Группы» находятся школьные классы. У администратора есть возможность создать класс, получить код приглашения, заполнить расписание уроков или скопировать в выбранный класс своё личное школьное расписание. Ученики вводят код во время регистрации и автоматически попадают в класс. Уже зарегистрированный пользователь может ввести код во вкладке «Группы».

Одноклассники видят общее расписание и список участников с кнопкой отправки заявки в друзья. Личные задачи, email и дополнительные занятия других людей не раскрываются. Для каждого пользователя предусмотрен один класс. Личные дополнительные занятия сохраняются и показываются вместе с общими уроками, а старые персональные школьные уроки не дублируются в календаре после вступления в класс.

Коды классов можно передавать нескольким ученикам. После создания или смены кода его нужно сохранить: для безопасности повторный просмотр не предусмотрен. Администратор может заменить код новым, тогда старый перестанет работать.

## Что есть в week.

### Календарь и задачи

В календаре можно смотреть один день или всю неделю. В режиме дня дела идут по времени с точным интервалом начала и окончания, например 09:25–10:05. Между занятиями и задачами сохраняются пустые участки временной шкалы с часовыми отметками. В режиме дня показывается примерно час до первого события и час после последнего, без пустой ночной шкалы. Чем длиннее промежуток, тем больше расстояние между карточками. У задачи есть название, описание, дата, время, длительность, категория, приоритет, цвет и, при необходимости, дедлайн. Поддерживаются повторения по дням, неделям и будням.

Плюс в пустом промежутке таймлайна открывает создание задачи с подставленным временем. На компьютере свою обычную задачу можно перетащить в свободный промежуток; на телефоне удержать карточку и затем выбрать место. Повторяющиеся задачи перемещаются через редактирование всей серии. Кнопки таймера, редактирования и удаления находятся справа от задачи и рассчитаны на нажатие с телефона. Если новая задача пересекается с другой задачей или занятием, week. предупредит об этом. При желании задачу всё равно можно сохранить.

Большую задачу можно разбить на чек-лист. Пункты отмечаются отдельно, а рядом с задачей видно, сколько уже сделано. В одном чек-листе может быть до 50 пунктов.

Если не успел закончить дела вчера, воспользуйся кнопкой «Перенести». Она появляется, когда есть незавершённые задачи за прошедшие дни. Выбранные дела переносятся на сегодня без старого времени начала.

### Расписание

Уроки и дополнительные занятия отображаются в календаре как обычные карточки без пунктирной обводки. Школьные занятия выделены голубым, дополнительные занятия фиолетовым. Цвета обычных задач выбираются при создании и редактировании. Поменять расписание можно через свой профиль, без повторного прохождения первоначальной настройки.

### Друзья и общие планы

Чтобы тебя могли найти, придумай username в профиле. В разделе «Друзья» можно искать других пользователей, отправлять заявки и принимать приглашения.

При создании задачи можно выбрать, для кого она:

- Только для себя.
- Общая с другом.
- Предложение другу, которое он сможет принять или отклонить.

Ответы на предложения находятся в разделе «Предложения».

### Частые задачи, таймер и статистика

Частые задачи можно сохранить как шаблоны. Если нужно понять, сколько времени ушло на дело, запусти таймер прямо у задачи.

В статистике отдельно учитываются задачи, школьные уроки и дополнительные занятия. Есть недельный график нагрузки, процент выполненных задач, категории и серия дней (streak), когда ты отметил хотя бы одну задачу выполненной. Серия начинает записываться после обновления базы и не восстанавливается задним числом.

## Профиль и настройки

Нажми на свой аватар внизу боковой панели. Там можно изменить имя и username, поправить расписание или выйти из аккаунта.

Рядом с профилем есть шестерёнка. В настройках находятся:

- светлая, тёмная и системная темы;
- уведомления и напоминания за 5, 10, 15 или 30 минут;
- стандартная длительность новой задачи;
- экспорт и импорт JSON.

На телефоне профиль открывается по аватарке справа в нижней панели, без отдельной подписи. Шестерёнка настроек находится вверху справа, над кнопкой добавления задачи.

**Про резервные копии:** экспорт создаёт JSON-файл с данными. Импорт в текущей версии рассчитан на локальный демо-режим и не восстанавливает данные в подключённой базе Supabase. Не удаляй данные из базы в расчёте на такой импорт.

## Для тех, кто хочет запустить week. у себя

Сайт состоит из обычных HTML, CSS и JavaScript. Для аккаунтов и хранения данных используется Supabase. Сборка через npm не нужна.

1. Создай проект в Supabase и открой SQL Editor.
2. Для новой базы выполни `supabase.sql`, затем миграции по порядку. Если у тебя уже работает старая версия week., не запускай полную схему повторно. Используй миграции по порядку: `MIGRATION_1_1.sql`, `MIGRATION_1_6.sql`, `MIGRATION_2_0.sql`, `MIGRATION_2_1.sql`, затем `MIGRATION_2_2_CLASSES.sql`. Миграция 2.1 добавляет индексы и закрывает прямой доступ к чужим email, а 2.2 создаёт классы, коды приглашения и единое расписание.
3. В Supabase SQL Editor выполни команду из `ADMIN_SETUP_2_2.sql`, заменив `ТВОЙ_EMAIL_ЗДЕСЬ` на email своего уже существующего аккаунта. Не сохраняй свой настоящий email в репозитории.
4. Укажи URL проекта и публичный ключ Supabase в `config.js`. Формат есть в `config.example.js`. Если обновляешь уже работающий сайт, сохрани свой настроенный `config.js`.
5. Опубликуй файлы на статическом хостинге, например GitHub Pages. `index.html` должен находиться в корне опубликованной папки.
6. Проверь вход, регистрацию, создание задач и работу с друзьями на разных аккаунтах.

Для push-уведомлений есть отдельная инструкция [`PUSH_SETUP.md`](PUSH_SETUP.md). Само по себе размещение сайта на GitHub Pages серверную отправку напоминаний не настраивает.

Не загружай в репозиторий секретные ключи Supabase, в том числе `service_role`, и приватный VAPID-ключ. Публичный ключ для браузера и `service_role` не одно и то же.

## Обновление 2.0

Быстрое создание и перемещение задач работают без новых полей. Чтобы появилась серия выполнений, выполни `MIGRATION_2_0.sql` на существующей базе. В ней будет не больше одной небольшой записи на человека в день. Школьные и дополнительные занятия входят в запланированную нагрузку, но не считаются выполненными задачами и не увеличивают streak. Для прошлых дней без сохранённой истории серия не восстанавливается автоматически.

Примечание: `TECHNICAL_DOCUMENTATION.docx` внутри архива описывает версию 1.6. Изменения 1.7–2.0 перечислены в этом README, подробная техническая документация отдельно не обновлялась.


## Оптимизация 2.1 для небольшой школы

Цель обновления: меньше лишних запросов, сохранение расписания и истории, защита личных данных. Ориентир составляет около 50 активных пользователей при обычном ежедневном использовании; гарантировать предел без нагрузки на настоящем проекте нельзя.

- Фоновые проверки предложений идут раз в 3 минуты и только когда страница активна. При возвращении после паузы выполняется полное обновление, если данные устарели.
- Обычные задачи загружаются на выбранный диапазон (45 дней назад и 75 вперёд). Старые незавершённые дела и регулярные задачи продолжают загружаться. При переходе за пределы диапазона данные обновляются.
- Друзей ищем через `public_profiles`: доступны имя и username, чужие email закрыты.
- Edge Function запрашивает задачи пакетно по дате, отправляет напоминание только владельцу или участнику общей задачи. Уведомления об общих задачах идут конкретным участникам.
- Service Worker не кладёт ответы внешнего API в кеш.
- Задачи не удаляются автоматически. Удаление записи также удаляет её историю таймера. За размером базы можно следить через `MAINTENANCE_2_1.sql`.

**Обновление действующего проекта:** сначала сделай резервную копию Supabase, выполни `MIGRATION_2_1.sql`, затем опубликуй новые файлы сайта. Если используешь push, отдельно повторно разверни `send-task-reminders` и проверь работу на двух аккаунтах. Одной загрузки в GitHub для обновления серверной функции недостаточно.

`TECHNICAL_DOCUMENTATION.docx` внутри архива относится к прежней версии 1.6. Изменения для 2.1 описаны в `OPTIMIZATION_2_1.md`.

## Обновление 2.2: классы

Для обновления существующей базы сначала сделай резервную копию и убедись, что миграции до 2.1 включительно уже выполнены. Затем выполни `MIGRATION_2_2_CLASSES.sql`. После неё выдай права нужному аккаунту через `ADMIN_SETUP_2_2.sql` из SQL Editor, обнови сайт, создай класс и скопируй код. Права администратора выдаются сервером: одного изменения JavaScript или HTML недостаточно. Подробности в `CLASSES_SETUP_2_2.md`.

`TECHNICAL_DOCUMENTATION.docx` из архива относится к более ранней версии 1.6; классы и оптимизация 2.1 описаны в отдельных инструкциях. Живое подключение к твоему Supabase в этом архиве не проверялось. Демо-режим нужен для проверки интерфейса, он не создаёт реальные аккаунты.


## Обновление 2.2.1: выбор дня при добавлении урока

В редакторе расписания класса и в личном расписании новая строка наследует последний выбранный день недели вместо автоматического возврата к понедельнику. SQL-миграция не требуется. Подробности в `CHANGELOG_2_2_1.md`.


## Обновление 2.2.2: перенос личного расписания в класс

У администратора в разделе «Группы» рядом с «Редактировать» появилась кнопка «Перенести моё расписание». Она считывает **только его собственные школьные уроки** из `schedule_items` и копирует их в расписание выбранного класса, предварительно спрашивая подтверждение. Старое общее расписание выбранного класса заменяется целиком; личное расписание и дополнительные занятия не меняются. Если в личном расписании нет школьных уроков, импорт не выполняется.

Право на запись проверяет уже имеющаяся защищённая функция `week_replace_class_schedule`, так что простое раскрытие кнопки в браузере не даёт прав обычному ученику. **Нового SQL для 2.2.2 нет**. При установке с версии 2.2.1 просто замени файлы сайта и обнови кеш. Миграции до 2.2 включительно должны быть применены, а роль администратора выдана через `ADMIN_SETUP_2_2.sql`.
