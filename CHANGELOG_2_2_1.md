# week. 2.2.1: день при добавлении уроков

Исправлен редактор расписания класса: при нажатии «+ Урок» следующий урок получает день недели, который администратор выбрал перед этим. Например, после переключения с понедельника на вторник новые строки также будут иметь вторник, пока день не изменят снова. Сохранённые уроки не меняют дату автоматически.

Аналогично работает добавление строк в личное школьное расписание и дополнительные занятия. Дни между разными редакторами не смешиваются; при повторном открытии расписания выбор начинается с текущих записей.

Для перехода с week. 2.2 достаточно заменить файлы сайта на содержимое архива. Дополнительной SQL-миграции нет. Если при входе остаётся ошибка `public.public_profiles`, необходимо применить `MIGRATION_2_1.sql` к рабочему проекту Supabase: это отдельная проблема схемы базы.
